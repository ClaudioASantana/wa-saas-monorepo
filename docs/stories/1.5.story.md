# Story 1.5: Route Middlewares (Auth & Guest)

**Epic:** [EPIC-1](../epics/epic-1-auth.md)
**Pontos:** 3
**Status:** Done

## Descrição
Proteger as rotas da aplicação configurando middlewares do Nuxt. Impedir acesso anônimo às áreas privadas e impedir que usuários já logados acessem telas públicas.

## Tarefas (Checklist)
- [x] Criar `middleware/auth.ts` para verificar a sessão do Supabase. Redirecionar para `/login` se não houver sessão ativa.
- [x] Criar `middleware/guest.ts` para redirecionar usuários logados que tentam acessar rotas públicas para a raiz `/`.
- [x] Aplicar middleware `auth` no `layouts/default.vue` ou diretamente nas rotas base de área privada (`/`, `/perfil`, `/assinatura`, `/workspace`).
- [x] Aplicar middleware `guest` nas páginas `/login` e `/esqueci-senha`.

## Critérios de Aceite
- Um usuário anônimo navegando para `/workspace/123/chat` é forçado a voltar para `/login`.
- Um usuário autenticado navegando para `/login` é forçado a voltar para a página inicial (seletor de workspaces).
- Transições de rota entre áreas protegidas ocorrem sem piscar a tela de login.
