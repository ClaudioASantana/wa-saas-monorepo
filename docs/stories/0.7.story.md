# Story 0.7: Recuperação e Redefinição de Senha

**Status:** Ready

Como um usuário, quero poder recuperar minha senha via e-mail e definir uma nova senha, para que eu não fique bloqueado do sistema caso esqueça minhas credenciais.

## Acceptance Criteria

1. **Solicitar Recuperação**: Na tela de login, link "Esqueceu a senha?" leva para `/esqueci-senha` com campo de e-mail.
2. **Envio de E-mail**: Ao submeter, chama `supabase.auth.resetPasswordForEmail()` e exibe mensagem de confirmação (sem revelar se e-mail existe ou não).
3. **Página de Redefinição**: Link no e-mail redireciona para `/redefinir-senha` com dois campos: nova senha e confirmação.
4. **Validação**: Senha mínima de 8 caracteres. Campos devem coincidir. Erros exibidos em tempo real.
5. **Conclusão**: Após redefinir com sucesso, redireciona para `/login` com toast de confirmação.
6. **Guards**: Middleware `guest` protege ambas as páginas (usuário logado é redirecionado para `/`).

## Technical Details

- **Auth**: `supabase.auth.resetPasswordForEmail(email, { redirectTo: '/redefinir-senha' })` para envio.
- **Redefinição**: `supabase.auth.updateUser({ password })` após capturar a sessão do link via `onAuthStateChange` com evento `PASSWORD_RECOVERY`.
- **Páginas**: `pages/esqueci-senha.vue` e `pages/redefinir-senha.vue` com layout `auth` (sem sidebar).
- **Composable**: Adicionar métodos `forgotPassword` e `resetPassword` ao `useAuth.ts` existente.
