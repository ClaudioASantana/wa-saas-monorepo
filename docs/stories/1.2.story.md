# Story 1.2: Login & Register UI

**Epic:** [EPIC-1](../epics/epic-1-auth.md)
**Pontos:** 5
**Status:** Done

## Descrição
Criar as interfaces visuais para o usuário realizar login ou criar uma nova conta, utilizando Tailwind CSS para estilização e componentes reutilizáveis.

## Tarefas (Checklist)
- [x] Criar componentes base de formulário (`BaseInput.vue`, `BaseButton.vue`).
- [x] Criar página `pages/login.vue` com abas ou toggle para "Entrar" e "Criar Conta".
- [x] Criar `components/login/LoginForm.vue` e integrá-lo com `useAuth()`.
- [x] Criar `components/login/RegisterForm.vue` e integrá-lo com `useAuth()`.
- [x] Tratar estados de loading (desabilitar botões) e mensagens de erro visuais.

## Critérios de Aceite
- UI renderizada sem tags `<style>`, utilizando puramente classes Tailwind CSS.
- Usuário consegue navegar entre os modos de login e registro.
- O preenchimento do formulário chama corretamente os métodos do Supabase.
- Feedback visual de sucesso ou erro é apresentado após a submissão.
