## Dev Notes

### Decisao de Framework Backend

Preferir **Fastify** por melhor performance e suporte nativo a TypeScript. Se houver restricao, usar Express.

### Supabase Client

Usar `createClient` com `SUPABASE_SERVICE_KEY` (service role) no backend para operacoes administrativas. Nunca expor essa chave no frontend.

```typescript
// src/config/supabase.ts
import { createClient } from '@supabase/supabase-js'

export const supabase = createClient(
  process.env.SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_KEY!
)
```

## Riscos

| Risco | Impacto | Mitigacao |
|-------|---------|-----------|
| Incompatibilidade de versoes entre Nuxt 3 e Node.js no monorepo workspace | Medio | Fixar versoes exatas no `package.json` raiz; testar `npm install` em ambiente limpo |
| `.env` com credenciais reais commitado por acidente | Alto | Adicionar `.env` ao `.gitignore` imediatamente; validar antes do primeiro commit |
| Estrutura de pastas escolhida agora dificulta escalar depois | Baixo | Seguir estrutura definida no escopo; nao inventar sub-pastas |
