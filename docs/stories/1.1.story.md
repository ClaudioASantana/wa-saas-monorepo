# Story 1.1: Supabase Auth Integration & Composables

**Epic:** [EPIC-1](../epics/epic-1-auth.md)
**Pontos:** 5
**Status:** Done

## Descrição
Configurar o módulo oficial `@nuxtjs/supabase` no projeto Nuxt e criar os composables base (ex: `useAuth()`) para abstrair os métodos de registro, login, logout e recuperação de senha.

## Tarefas (Checklist)
- [x] Instalar o módulo `@nuxtjs/supabase`.
- [x] Configurar chaves de API (`SUPABASE_URL`, `SUPABASE_KEY`) no `.env` e no `nuxt.config.ts`.
- [x] Criar arquivo `composables/useAuth.ts`.
- [x] Implementar método genérico de login com email/senha.
- [x] Implementar método genérico de registro (signup).
- [x] Implementar método genérico de logout.

## Critérios de Aceite
- O Nuxt se conecta com sucesso ao Supabase usando as credenciais do `.env`.
- Os métodos de auth respondem corretamente com sucesso ou erro fornecidos pela API do Supabase.
