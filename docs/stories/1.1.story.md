# Story 1.1: Conversation Assignment

Como um agente, quero poder assumir uma conversa ou atribuí-la a outro colega, para que possamos organizar melhor os atendimentos.

## Acceptance Criteria

1.  **Atribuição Manual**: O agente pode clicar em um botão "Assumir Conversa" (ou similar) no cabeçalho do chat.
2.  **Visualização do Responsável**: A lista de conversas e o cabeçalho do chat devem mostrar quem é o agente atual.
3.  **Filtros de Lista**: Deve haver um filtro/aba para ver apenas as conversas "Minhas" (atribuídas ao usuário logado) vs "Todas".
4.  **Notificação Real-time**: Quando uma conversa é atribuída, todos os agentes online devem ver a atualização na UI sem refresh.

## Technical Details

- **Database**: Coluna `agent_id` na tabela `conversations`.
- **API**: Novo endpoint `POST /api/chat/assign` recebendo `conversationId` e opcionalmente `agentId`.
- **Socket.IO**: Emitir evento `conversation:assigned` com os detalhes da nova atribuição.
