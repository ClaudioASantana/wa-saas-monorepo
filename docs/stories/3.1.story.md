# Story 3.1: CRM Kanban Funcional

**Status:** Ready

Como um gestor, quero um quadro Kanban de funil de vendas integrado ao WhatsApp, para que eu possa visualizar e mover conversas entre etapas do processo de vendas/suporte de forma visual.

## Acceptance Criteria

1. **Quadro Kanban**: Colunas representando etapas (ex: Novo Lead, Em Contato, Proposta, Fechado, Perdido). Default com 5 colunas criadas automaticamente ao primeiro uso.
2. **Cards de Conversa**: Cada card exibe nome do contato, preview da última mensagem e agente responsável.
3. **Arrastar e Soltar**: Cards podem ser movidos entre colunas via drag-and-drop. Movimento persiste no banco.
4. **Múltiplos Funis**: Botão "+ Novo Funil" permite criar funis com nomes customizados. Selector de funil ativo no topo.
5. **Adicionar Conversa**: Botão "Adicionar" em cada coluna abre busca de conversas do workspace para adicionar ao funil.
6. **Remover do Funil**: Opção no card para remover a conversa do funil (não apaga a conversa).
7. **Badge Real-time**: Se uma nova mensagem chega em uma conversa que está no Kanban, o card exibe um badge de notificação.

## Technical Details

- **Rota**: `/workspace/[id]/crm` → `pages/workspace/[id]/crm.vue` (página já existe, implementar).
- **Schema DB**: Nova migration com tabelas:
  - `crm_funnels`: `id, workspace_id, tenant_id, name, created_at`
  - `crm_stages`: `id, funnel_id, tenant_id, name, position, color`
  - `crm_cards`: `id, stage_id, conversation_id, tenant_id, position, created_at`
- **Drag & Drop**: Usar `@vueuse/core` `useDraggable` ou biblioteca `vue-draggable-plus`.
- **API**: Endpoints `GET/POST /api/crm/funnels`, `PATCH /api/crm/cards/[id]` (para mover entre stages).
- **Real-time**: Escutar evento `message:new` do Socket.IO já existente para marcar badge nos cards.
