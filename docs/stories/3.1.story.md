# Story 3.1: CRM Kanban Funcional

**Status:** Done

Como um gestor, quero um quadro Kanban de funil de vendas integrado ao WhatsApp, para que eu possa visualizar e mover conversas entre etapas do processo de vendas/suporte de forma visual.

## Acceptance Criteria

1. **Quadro Kanban**: Colunas representando etapas (ex: Novo Lead, Em Contato, Proposta, Fechado, Perdido). Default com 5 colunas criadas automaticamente ao primeiro uso.
2. **Cards de Conversa**: Cada card exibe nome do contato, preview da última mensagem e agente responsável.
3. **Arrastar e Soltar**: Cards podem ser movidos entre colunas via drag-and-drop. Movimento persiste no banco.
4. **Múltiplos Funis**: Botão "+ Novo Funil" permite criar funis com nomes customizados. Selector de funil ativo no topo.
5. **Adicionar Conversa**: Botão "Adicionar" em cada coluna abre busca de conversas do workspace para adicionar ao funil.
6. **Remover do Funil**: Opção no card para remover a conversa do funil (não apaga a conversa).
7. **Badge Real-time**: Se uma nova mensagem chega em uma conversa que está no Kanban, o card exibe um badge de notificação.

## Technical Details

- **Rota**: `/workspace/[id]/crm` → `pages/workspace/[id]/crm.vue` (página já existe, implementar).
- **Schema DB**: Nova migration com tabelas:
  - `crm_funnels`: `id, workspace_id, tenant_id, name, created_at`
  - `crm_stages`: `id, funnel_id, tenant_id, name, position, color`
  - `crm_cards`: `id, stage_id, conversation_id, tenant_id, position, created_at`
- **Drag & Drop**: Usar `@vueuse/core` `useDraggable` ou biblioteca `vue-draggable-plus`.
- **API**: Endpoints `GET/POST /api/crm/funnels`, `PATCH /api/crm/cards/[id]` (para mover entre stages).
- **Real-time**: Escutar evento `message:new` do Socket.IO já existente para marcar badge nos cards.

## Resumo da Implementação (Atualização 11/05/2026)

A implementação e o refinamento do Kanban CRM foram concluídos com sucesso. As principais melhorias na arquitetura e experiência incluem:

1. **Persistência de Notificações de Mensagens**:
   - Ajustada a query no backend (`stages.get.ts`) para incluir a coluna `unread_count` que já existia na tabela `conversations`.
   - Agora, ao carregar a página do CRM, a flag `hasNewMessages` é inicializada de forma persistente com base nas mensagens não lidas (`unread_count > 0`).

2. **Refinamento do Drag-and-Drop (Reordenação)**:
   - Aprimorada a lógica de reposicionamento no `KanbanBoard.vue`. Agora é calculado o ponto médio `(prev.position + next.position) / 2` entre o card anterior e o próximo, tornando a reordenação muito mais robusta.
   - Adicionadas animações visuais para melhor feedback do usuário ao arrastar um card (`ghost-class` e `drag-class` com rotação e escala).

3. **Integração Fluida com o Chat**:
   - Cards (`KanbanCard.vue`) agora são clicáveis. Ao clicar em um card do CRM, a plataforma abre a conversa correspondente.
   - O `crm.vue` foi atualizado para navegar usando o query parameter `?c=[conversation_id]`.
   - O componente `chat.vue` lê o parâmetro `?c=` da URL (`route.query.c`) e auto-seleciona a conversa ao abrir, marcando-a automaticamente como lida.

4. **Tratamentos Extras e QA**:
   - Erros de TypeScript (como `TS2339` relacionado a `.contact`) gerados no `crm.vue` durante compilações locais foram corrigidos.
   - O projeto foi compilado para produção (`npm run build`) com sucesso, validando que todos os componentes desenvolvidos estão estritos e livres de erros.
