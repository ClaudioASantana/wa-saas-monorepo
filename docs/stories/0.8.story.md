# Story 0.8: Pinia Cache Global

**Status:** Ready

Como desenvolvedor, quero que dados frequentemente acessados (perfil do usuário, workspaces, configurações) sejam cacheados via Pinia, para reduzir consultas repetidas ao Supabase e melhorar a performance percebida.

## Acceptance Criteria

1. **Store de Usuário**: `useUserStore` carrega perfil do usuário logado uma única vez no plugin de inicialização. Todos os componentes leem da store, não do Supabase diretamente.
2. **Store de Workspace**: `useWorkspaceStore` carrega dados do workspace ativo (nome, plano, tenant_id) ao entrar em `/workspace/[id]/...`. Evita re-fetch entre navegações internas.
3. **Store de Agentes**: `useAgentsStore` carrega a lista de agentes do workspace. Usada por `ConversationAssignment.vue` em vez de fazer fetch a cada conversa selecionada.
4. **Invalidação**: Ao sair do workspace ou fazer logout, stores são resetadas via `$reset()`.
5. **Plugin de Init**: `plugins/init.client.ts` executa ao carregar o app, popula `useUserStore` se houver sessão ativa.

## Technical Details

- **Stores**: `stores/user.ts`, `stores/workspace.ts`, `stores/agents.ts`.
- **Plugin**: `plugins/init.client.ts` usa `useSupabaseUser()` e chama `userStore.init()`.
- **Integração**: Atualizar `chat.vue` para usar `useAgentsStore` no lugar do fetch de agentes inline.
- **Persistência**: Não usar persistência em localStorage (dados sensíveis). Apenas memória de sessão.
