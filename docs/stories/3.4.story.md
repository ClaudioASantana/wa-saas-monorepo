# Story 3.4: Internal Timeline (Notes & Logs)

**Status:** Done

Como um agente, quero poder deixar notas internas e ver o histórico de ações na conversa, para colaborar melhor com o time sem que o cliente veja.

## Acceptance Criteria

1.  **Notas Internas**: O agente pode enviar uma mensagem marcada como "Nota Interna".
2.  **Renderização Diferenciada**: Notas internas devem ter um fundo de cor diferente (ex: amarelo/pastel) para destacar que não foram enviadas ao WhatsApp.
3.  **Logs de Sistema**: Ações como "Chat atribuído a X" ou "Status alterado para Resolvido" devem aparecer no timeline como mensagens de sistema.

## Technical Details

- **Database**: Usar coluna `type = 'note'` ou `metadata->'is_internal' = true` na tabela `messages`.
- **UI**: `MessageItem.vue` deve verificar se é uma nota e ajustar o estilo.

## Checklist

- [ ] Ajustar `ChatService.insertMessage` para suportar mensagens internas
- [ ] Criar componente de input para notas no `ChatWindow.vue`
- [ ] Estilizar `MessageItem.vue` para notas e mensagens de sistema
- [ ] Gerar mensagens de log automático ao realizar ações (ex: atribuição)
