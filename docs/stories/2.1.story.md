# Story 2.1: Isolamento de Tenants (Database)

**Epic:** [EPIC-2](../epics/epic-2-workspaces.md)
**Pontos:** 5
**Status:** Done

## Descrição
Garantir o multi-tenancy criando a estrutura base de workspaces e user_workspaces no banco de dados.

## Tarefas (Checklist)
- [x] Criar tabela `workspaces` via migration com Row Level Security.
- [x] Criar tabela pivot `user_workspaces` para definir papéis (owner, admin, agent).
- [x] Implementar triggers para auto-atribuir o criador como 'owner'.

## Critérios de Aceite
- Dados são rigidamente separados.
- Queries protegidas via RLS garantem que usuários só veem dados de workspaces que eles participam.
