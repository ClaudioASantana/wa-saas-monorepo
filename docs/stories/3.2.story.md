# Story 3.2: Smart Routing — Distribuição Automática de Conversas

**Status:** Done

Como um gestor, quero que novas conversas sejam distribuídas automaticamente aos agentes disponíveis, para que nenhum atendimento fique sem responsável e a carga seja balanceada.

## Acceptance Criteria

1. **Round-Robin**: Novas conversas são distribuídas ciclicamente entre agentes ativos do workspace (status `active`).
2. **Retenção por Agente**: Se o contato já conversou antes com um agente específico nos últimos 7 dias, a conversa retorna ao mesmo agente (se disponível).
3. **Distribuição por Tag**: Nas configurações do workspace, é possível mapear Tags para agentes/grupos. Uma conversa com a tag "Suporte" vai para agentes do grupo Suporte.
4. **Fallback**: Se nenhum agente está disponível (todos offline), a conversa fica sem atribuição e aparece na fila "Aguardando".
5. **Configuração**: Página de configurações do workspace tem seção "Roteamento" com toggle para ativar/desativar cada regra.
6. **Log**: Cada atribuição automática gera uma mensagem de sistema interna na conversa ("Conversa atribuída automaticamente via Round-Robin").

## Technical Details

- **Trigger**: Lógica disparada no `webhook-worker.ts` ao criar/retomar uma conversa (`upsertConversation`).
- **Serviço**: Criar `RoutingService` em `server/services/routing.service.ts` com métodos:
  - `findAgentByRoundRobin(workspaceId, tenantId)`
  - `findLastAgentForContact(contactId, tenantId)`
  - `findAgentByTag(tagId, tenantId)`
- **Schema DB**: Nova migration `routing_config` com `workspace_id, round_robin_enabled, retention_days, tag_routing (jsonb)`.
- **Estado Round-Robin**: Usar Redis (`INCR` + `key = rr:{workspaceId}`) para manter o índice atual sem consultar o banco.
- **UI**: Seção "Roteamento" em `pages/workspace/[id]/configuracoes.vue`.
