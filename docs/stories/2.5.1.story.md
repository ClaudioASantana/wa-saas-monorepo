# Story 2.1: Respostas Rápidas (Quick Replies)

Como um agente, quero poder usar atalhos rápidos para enviar mensagens frequentes, para que eu possa atender mais clientes em menos tempo.

## Acceptance Criteria

1.  **Gerenciamento (CRUD)**: Administradores e Supervisores podem criar, editar e excluir respostas rápidas no painel de configurações.
2.  **Atalho no Chat**: Ao digitar `/` no campo de mensagem do `ChatWindow.vue`, uma lista pop-over deve aparecer com as respostas disponíveis.
3.  **Variáveis Dinâmicas**: O sistema deve substituir variáveis como `{contato}` pelo nome do contato atual.
4.  **Seleção e Envio**: O agente pode selecionar uma resposta via teclado (setas + enter) ou mouse, preenchendo o campo de mensagem.
5.  **Multitenancy**: Respostas rápidas são isoladas por `workspace_id`.

## Technical Details

- **Database**: Nova tabela `quick_replies` (`id`, `workspace_id`, `shortcut`, `content`, `created_at`).
- **Frontend**: Componente `UCommandPalette` ou similar para a lista de atalhos.
- **Backend**: API CRUD em `server/api/workspace/quick-replies`.
