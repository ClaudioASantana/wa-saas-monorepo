# Story 2.5.3: Tags & Categorização

**Status: ✅ Done**

Como um agente, quero poder adicionar tags às conversas (ex: "Lead Quente", "Suporte", "Financeiro"), para que eu possa organizar e filtrar os atendimentos de forma mais eficiente.

## Acceptance Criteria

1.  **Gerenciamento de Tags**: Administradores podem criar e gerenciar a lista de tags globais do workspace (nome e cor).
2.  **Atribuição no Chat**: O agente pode adicionar ou remover tags de uma conversa ativa através da barra lateral ou cabeçalho do chat.
3.  **Filtragem**: A lista de conversas deve permitir filtrar por uma ou mais tags.
4.  **Visualização**: As tags atribuídas devem aparecer como badges na lista de conversas e no cabeçalho do chat.
5.  **Persistência**: As tags devem ser salvas no banco de dados vinculadas à conversa.

## Technical Details

- **Database**:
  - Tabelas `tags` e `conversation_tags` em `supabase/migrations/20260311000003_create_tags.sql`.
- **Backend**:
  - API CRUD de tags: `apps/web/server/api/workspace/[id]/tags/`
  - API de vínculo com conversas: `apps/web/server/api/chat/conversations/[id]/tags` (POST)
- **Frontend**:
  - Gerenciamento: `apps/web/components/admin/TagsManager.vue`
  - Atribuição no chat: integrado no `ChatWindow.vue` (popover no cabeçalho)
  - Filtragem: `ConversationList.vue` com emit `update:tagFilter`
