# Story 1.4: Profile Trigger & Pinia State (Nuxt Plugin)

**Epic:** [EPIC-1](../epics/epic-1-auth.md)
**Pontos:** 5
**Status:** Done

## Descrição
Criar a trigger no banco de dados para sincronizar novos usuários com a tabela `profiles` e desenvolver o cache global de usuário utilizando Pinia e Nuxt Plugins.

## Tarefas (Checklist)
- [x] Criar script SQL para a Trigger no PostgreSQL do Supabase (tabela `auth.users` -> `public.profiles`).
- [x] Configurar Store no Pinia `stores/useUserStore.ts` com estado de `profile` e `workspaces`.
- [x] Criar um Plugin do Nuxt (`plugins/auth-init.ts`) que busca os dados da tabela `profiles` assim que a aplicação carrega (se houver usuário logado) e salva no Pinia.

## Critérios de Aceite
- Um novo registro de usuário gera instantaneamente uma linha correspondente na tabela `profiles`.
- Ao fazer refresh da página logado, o plugin consulta a tabela `profiles` apenas uma vez e armazena os dados básicos (Nome, Email) no estado global.
- Componentes podem acessar o `useUserStore()` de forma síncrona sem precisar consultar o banco de dados.
