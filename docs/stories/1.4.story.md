# Story 1.4: Página de Contatos

**Status:** Ready

Como um agente, quero visualizar, buscar e gerenciar os contatos do workspace, para que eu possa ter uma visão centralizada dos clientes e editar suas informações sem precisar abrir uma conversa.

## Acceptance Criteria

1. **Listagem**: Tabela paginada com colunas: Nome, Telefone, Última Conversa (data), Status (ativo/inativo), Notas (trecho).
2. **Busca**: Campo de busca em tempo real filtra por nome ou telefone.
3. **Detalhe / Edição**: Ao clicar em um contato, abre painel lateral (ou modal) com todos os campos editáveis: Nome, Telefone, Notas.
4. **Salvar**: Botão "Salvar" atualiza o contato via API e exibe toast de confirmação.
5. **Ir para Conversa**: Botão "Ver Conversa" no painel lateral navega para `/workspace/[id]/chat` com a conversa do contato selecionada.
6. **Exportar**: Botão "Exportar CSV" gera e faz download de `contatos.csv` com todos os dados visíveis.

## Technical Details

- **Rota**: `/workspace/[id]/contatos` → `pages/workspace/[id]/contatos.vue`.
- **API Read**: Query direta ao Supabase via `useAsyncData` filtrando `contacts` por `workspace_id` (via join com `conversations`).
- **API Update**: Endpoint `PATCH /api/contacts/[id]` com `serverSupabaseUser` para autenticação.
- **Exportação**: Gerada no client-side convertendo o array de contatos para CSV via função utilitária.
- **Paginação**: Usar `.range()` do Supabase com `limit = 50`.
