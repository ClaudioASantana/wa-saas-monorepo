# Story 1.3: Real-time Presence

Como um agente, quero saber se outros colegas estão online ou digitando na mesma conversa, para evitar duplicidade de atendimento e melhorar a colaboração.

## Acceptance Criteria

1.  **Status Online**: Mostrar um indicador visual (ex: bolinha verde) nos colegas que estão com o dashboard aberto.
2.  **Quem está vendo**: No cabeçalho do chat, mostrar avatares dos agentes que estão com aquela conversa específica aberta.
3.  **Indicador de Digitação**: Mostrar "Agente X está digitando..." quando outro colega estiver escrevendo uma resposta.

## Technical Details

- **Socket.IO**: Usar `rooms` por `conversationId` para rastrear quem está vendo cada chat.
- **Presence**: Implementar um sistema de heartbeat ou usar a funcionalidade de presença do Socket.IO para rastrear usuários online no tenant.

## Checklist

- [ ] Implementar `agent:viewing` e `agent:typing` via Socket.IO
- [ ] Criar componente de presença no cabeçalho do chat
- [ ] Atualizar `useWebSocket` para emitir eventos de digitação
