# Story 1.3: Recuperação de Senha & Redefinição

**Epic:** [EPIC-1](../epics/epic-1-auth.md)
**Pontos:** 3
**Status:** Done

## Descrição
Implementar o fluxo de "Esqueci minha senha" para permitir que os usuários recuperem acesso às suas contas recebendo um link mágico por e-mail e redefinindo a senha.

## Tarefas (Checklist)
- [x] Adicionar método `resetPassword` no composable `useAuth.ts`.
- [x] Criar página `pages/esqueci-senha.vue` com o formulário de solicitação.
- [x] Criar página `pages/redefinir-senha.vue` para definir a nova senha após clicar no link do e-mail.
- [x] Configurar a URL de redirecionamento do Supabase Email Template para apontar para `/redefinir-senha`.

## Critérios de Aceite
- O usuário pode inserir seu e-mail e receber o link de recuperação do Supabase.
- Ao clicar no link no e-mail, o usuário é levado à rota correta para inserir a nova senha.
- A nova senha é definida e o usuário é automaticamente autenticado ou redirecionado para o login.
