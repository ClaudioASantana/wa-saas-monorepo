# Story 7.1: Dashboard Analítico Avançado

**Status:** Done

Como um gestor, quero métricas avançadas de atendimento no dashboard, para que eu possa acompanhar a performance da equipe e identificar gargalos.

## Acceptance Criteria

1. **TMR (Tempo Médio de Resposta)**: Tempo médio entre chegada de mensagem inbound e primeira resposta outbound do agente, exibido em minutos.
2. **TMRes (Tempo Médio de Resolução)**: Tempo médio entre abertura e resolução de conversa, exibido em horas.
3. **Volume por Agente**: Gráfico de barras mostrando quantidade de conversas resolvidas por agente no período.
4. **Filtro de Período**: Seletor de período (hoje, 7 dias, 30 dias, personalizado) aplicado a todos os cards.
5. **Conversas por Hora**: Gráfico de linha com volume de mensagens recebidas por hora do dia (padrão de pico).
6. **Taxa de Resolução**: % de conversas resolvidas vs abertas no período.

## Technical Details

- **Endpoint**: `GET /api/workspace/[id]/analytics?period=7d` retornando objeto com todas as métricas.
- **TMR**: Query SQL calculando `AVG(primeira_resposta_outbound.created_at - ultima_mensagem_inbound.created_at)` agrupado por conversa.
- **Gráficos**: Usar `@nuxtjs/chart` ou `chart.js` (já verificar se está no package.json; caso não, adicionar `chart.js` + `vue-chartjs`).
- **Performance**: Queries agregadas no backend, não no client. Usar `created_at` indexes já existentes.
