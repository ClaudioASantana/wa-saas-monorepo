## Escopo

### Utilitario de Tempo UTC

```typescript
// src/utils/time.ts

/**
 * Retorna o timestamp atual em UTC.
 * SEMPRE usar esta funcao em vez de `new Date()` diretamente.
 */
export function utcNow(): Date {
  return new Date(new Date().toISOString())
}

/**
 * Adiciona horas a um timestamp UTC.
 */
export function addHours(date: Date, hours: number): Date {
  return new Date(date.getTime() + hours * 60 * 60 * 1000)
}

/**
 * Verifica se um timestamp UTC ja expirou.
 */
export function isExpired(expiresAt: Date): boolean {
  return utcNow() > expiresAt
}
```

### Logger Estruturado

```typescript
// src/config/logger.ts
import pino from 'pino'

export const logger = pino({
  level: process.env.LOG_LEVEL || 'info',
  formatters: {
    level: (label) => ({ level: label }),
  },
  timestamp: () => `,"time":"${new Date().toISOString()}"`, // UTC ISO 8601
})
```

### Request Logger Middleware

```typescript
// src/middleware/request-logger.ts
export async function requestLogger(req, reply) {
  const start = Date.now()
  req.requestId = crypto.randomUUID()

  reply.addHook('onSend', async () => {
    logger.info({
      request_id: req.requestId,
      tenant_id: req.tenantId,
      method: req.method,
      path: req.url,
      status: reply.statusCode,
      duration_ms: Date.now() - start,
      time: new Date().toISOString(),
    })
  })
}
```

## Dev Notes

### Por que TIMESTAMPTZ e nao TIMESTAMP?

`TIMESTAMPTZ` (timestamp with time zone) armazena o valor em UTC internamente e converte para o timezone da sessao na leitura. Isso elimina bugs de expiracao de janela de 24h causados por offset de fuso horario.

### Convencao de Codigo

**SEMPRE** usar `utcNow()` em vez de `new Date()`:

```typescript
// Errado
const expiresAt = new Date(Date.now() + 24 * 60 * 60 * 1000)

// Correto
const expiresAt = addHours(utcNow(), 24)
```

### Impacto no Negocio

A janela de 24h (PRD secao 4.1) e checada no momento exato do envio. Um bug de timezone pode fazer o sistema bloquear envios que ainda estariam validos, ou pior, permitir envios gratuitos apos a expiracao, gerando custo nao previsto.

## Riscos

| Risco | Impacto | Mitigacao |
|-------|---------|-----------|
| Dev usar `new Date()` diretamente em vez de `utcNow()` causando bug de janela de 24h | **Critico** | ESLint custom rule ou pre-commit hook bloqueando `new Date()` no codigo de negocio |
| Log estruturado em JSON dificultando leitura em desenvolvimento local | Baixo | Adicionar `pino-pretty` como devDependency para output legivel em `NODE_ENV=development` |
| `TIMESTAMPTZ` convertido para timezone errado por ORM/query builder | Medio | Testar com query direta no Supabase; documentar convencao no README |
| Logs excessivos em producao aumentando custo de storage | Baixo | Configurar `LOG_LEVEL=warn` em producao; `debug` apenas em desenvolvimento |
