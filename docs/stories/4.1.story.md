# Story 4.1: Perfil do Usuário

**Status:** Ready

Como um usuário, quero visualizar e editar meus dados de perfil, para que minhas informações estejam sempre atualizadas no sistema.

## Acceptance Criteria

1. **Rota**: `/perfil` exibe nome, e-mail (readonly), telefone e avatar do usuário logado.
2. **Editar Nome/Telefone**: Campos editáveis com botão "Salvar". Toast de confirmação ao salvar.
3. **Alterar Senha**: Seção separada com campos "Senha atual", "Nova senha" e "Confirmar nova senha".
4. **Avatar**: Upload de imagem (JPG/PNG, máx 2MB) que salva no Supabase Storage e atualiza o avatar exibido na sidebar.
5. **Guard**: Middleware `auth` protege a rota.

## Technical Details

- **Página**: `pages/perfil.vue` com layout padrão (sem sidebar de workspace).
- **API**: `PATCH /api/profile` usando `serverSupabaseUser` + `supabase.auth.updateUser()` para senha.
- **Storage**: Bucket `avatars` no Supabase Storage com path `{userId}/avatar.{ext}`.
- **Schema**: Tabela `profiles` já existente — atualizar `name` e `phone` via API.
