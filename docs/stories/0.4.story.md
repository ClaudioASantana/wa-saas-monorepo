## Escopo

### Eventos WebSocket (Contrato Inicial)

```typescript
// Eventos servidor -> cliente
type ServerEvents = {
  'message:new': {
    conversationId: string
    messageId: string
    content: string
    from: string
    timestamp: string // UTC ISO 8601
  }
  'conversation:status_changed': {
    conversationId: string
    status: 'active' | 'requesting' | 'intervened' | 'history'
    agentId?: string
  }
  'connection:ack': {
    sessionId: string
    tenantId: string
  }
}
```

### Servidor Node.js (socket.io)

```typescript
// src/realtime/websocket-server.ts
import { Server } from 'socket.io'

const io = new Server(httpServer, {
  cors: { origin: process.env.FRONTEND_URL },
})

io.use(async (socket, next) => {
  // Validar JWT e extrair tenantId
  const token = socket.handshake.auth.token
  const { tenantId, agentId } = await validateJWT(token)
  socket.data.tenantId = tenantId
  socket.data.agentId = agentId
  next()
})

io.on('connection', (socket) => {
  // Juntar sala do tenant para isolamento
  socket.join(`tenant:${socket.data.tenantId}`)
  socket.emit('connection:ack', {
    sessionId: socket.id,
    tenantId: socket.data.tenantId,
  })
})

// Emitir para todos agentes de um tenant
export function emitToTenant(tenantId: string, event: string, data: unknown) {
  io.to(`tenant:${tenantId}`).emit(event, data)
}
```

### Cliente Nuxt.js

```typescript
// composables/useWebSocket.ts
import { io } from 'socket.io-client'

export function useWebSocket() {
  const socket = io(useRuntimeConfig().public.apiUrl, {
    auth: { token: useAuthToken() },
    reconnectionDelayMax: 30000,
    reconnectionAttempts: Infinity,
  })

  const onNewMessage = (callback) => socket.on('message:new', callback)
  const onStatusChanged = (callback) => socket.on('conversation:status_changed', callback)

  return { socket, onNewMessage, onStatusChanged }
}
```

## Dev Notes

### Por que socket.io e nao ws nativo?

socket.io oferece: reconexao automatica, rooms (isolamento por tenant), fallback para long-polling (util em ambientes com proxy), e namespace. Para Nuxt.js SSR, o cliente so conecta no lado do cliente (`onMounted`).

### Isolamento por Tenant

Cada agente e adicionado a sala `tenant:{tenantId}` no momento da conexao. Ao emitir eventos, usar `io.to('tenant:{id}').emit(...)` para garantir que somente agentes do mesmo tenant recebem o evento.

### JWT no Handshake

O token JWT deve ser enviado no handshake (nao em cada mensagem). Validar e extrair `tenantId` e `agentId` uma unica vez na conexao.

## Riscos

| Risco | Impacto | Mitigacao |
|-------|---------|-----------|
| socket.io causando hydration errors no Nuxt 3 SSR | Alto | Inicializar socket APENAS em `onMounted` (client-only); nunca no setup SSR |
| Token JWT expirado mantendo conexao WebSocket ativa | Medio | Implementar verificacao periodica do token no servidor (heartbeat com revalidacao) |
| Numero de conexoes simultaneas esgotando file descriptors do servidor | Medio | Configurar `ulimit` em producao; monitorar conexoes abertas em `/metrics` |
| Agente recebendo eventos de outro tenant por bug de room assignment | **Critico** | Teste de isolamento automatizado obrigatorio; auditar `socket.join()` |
