# EPIC 2: Productivity & Automation

**Status:** In Progress
**Prioridade:** Alta

## Visão Geral
Este épico foca em aumentar a produtividade dos agentes e automatizar tarefas repetitivas no atendimento. O objetivo é reduzir o tempo de resposta e padronizar a comunicação com os clientes.

## Funcionalidades Principais
1. **Respostas Rápidas (Quick Replies)**: Atalhos para mensagens frequentes.
2. **Tags & Categorização**: Organização de contatos e conversas.
3. **Internal Automation**: Gatilhos básicos baseados em eventos.

## User Stories
- [ ] **Story 2.1**: Como um agente, quero usar atalhos (`/`) para enviar mensagens pré-definidas.
- [ ] **Story 2.2**: Como um gestor, quero criar e gerenciar um repositório de respostas rápidas para minha equipe.
- [ ] **Story 2.3**: Como um agente, quero adicionar tags às conversas para filtragem posterior.
