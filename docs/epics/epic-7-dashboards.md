# EPIC 7: Dashboards Analíticos

**Status:** Done
**Prioridade:** Média

## Visão Geral
Permitir que os donos de workspaces (tenants) acompanhem a produtividade de seus agentes e o volume de tickets através de uma interface analítica rica.

## Funcionalidades Principais
1. **Overview Rápido:** Cards com TMR, volume de mensagens recebidas no dia e resolução.
2. **Consultas Otimizadas:** APIs agregadas direto no Supabase, evitando vazamentos de memória na busca por volume bruto de dados.
3. **Feed Recente:** Tabela consolidando as conversas abertas recentemente para atuação imediata.
