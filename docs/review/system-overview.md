# Flux CRM - Visão Geral do Sistema

A tela inicial carregada logo após o login é o **Seletor de Workspaces**. 
No Flux CRM, um usuário pode fazer parte de várias agências ou empresas. Por isso, a primeira tela mostra os "cards" dos workspaces que você tem acesso. Ao criar a conta, você terá apenas um card (que é o seu próprio workspace/empresa).

## Como o Sistema Funciona (O Fluxo Principal)

Quando você clica no card do seu workspace, você entra de fato no sistema. A partir daí, você verá um menu lateral com as seguintes ferramentas:

1. 📊 **Dashboard (Painel):**
   É a visão geral. Aqui você verá métricas rápidas sobre quantos atendimentos estão abertos, quantas mensagens foram trocadas, etc.

2. 💬 **Atendimentos (O Coração do CRM):**
   É aqui que a mágica acontece. Essa tela funciona como um "WhatsApp Web com superpoderes". 
   - Os clientes enviam mensagens para o seu número de WhatsApp e elas caem aqui.
   - A tela é dividida em formato de **Kanban** (colunas). Você pode arrastar a conversa do cliente da coluna "Novo Lead" para "Em Negociação" ou "Venda Fechada".

3. 👥 **Contatos:**
   Sua agenda inteligente. Todos os clientes que entrarem em contato pelo WhatsApp ficam salvos aqui automaticamente.

4. 🚥 **Funis e Estágios:**
   Aqui você personaliza o seu Kanban. Se você vende carros, pode criar colunas como "Agendou Test Drive". Se vende serviços, pode ser "Reunião Marcada". Você cria o funil de vendas do seu jeito.

5. ⚙️ **Configurações:**
   A parte administrativa do seu negócio.
   - **Canais:** É onde você vai conectar o seu número de WhatsApp (lendo um QR Code, por exemplo).
   - **Templates:** Onde você gerencia mensagens automáticas/rápidas.
   - **Equipe:** Onde você convida outros vendedores ou atendentes para acessarem esse mesmo workspace e responderem os clientes junto com você.
